# 🛍️ Handcrafted Creations – Shopify E-commerce Website

## 📌 Project Overview

This project is a fully functional e-commerce website built using **Shopify**, focused on selling handcrafted products such as:

* 🖼️ Handcrafted Frames
* 💌 Handcrafted Cards
* 🪔 Handcrafted Diyas

The goal of this project is to showcase traditional handmade items through a modern, user-friendly online store, providing customers with a seamless shopping experience.

---

## 🚀 Features

### 🏠 Home Page

* Hero section with engaging visuals and messaging
* Featured products display
* Product collections highlighting categories
* Clean and responsive layout

### 📦 Product Pages

* Detailed product descriptions
* Pricing and images
* Add-to-cart functionality

### 🛒 Cart Page

* View selected items
* Update quantity or remove products
* Checkout flow integration

### 📖 About Page

* Custom-designed section using **Liquid code**
* Brand story and purpose
* Emphasis on handcrafted authenticity

### 📞 Contact Page

* Customer inquiry form
* Basic contact details

---

## 🛠️ Technologies Used

* **Shopify** – E-commerce platform
* **Liquid** – Shopify templating language
* **HTML5 & CSS3** – Structure and styling
* **JavaScript (basic)** – Interactivity
